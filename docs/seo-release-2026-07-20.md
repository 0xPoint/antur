## Настоящие 301

Production работает на GitHub Pages. Файл `public/_redirects` уже содержит карту старых URL, но
GitHub Pages не исполняет этот формат и отдает сгенерированные HTML-заглушки с HTTP 200.

Для настоящих 301 нужно перенести production на платформу с edge/server redirects (например,
Cloudflare Pages или Netlify), подключить домен и только после проверки переключить DNS. При таком
развертывании существующий `public/_redirects` становится источником правил. Критерий приемки:

```text
curl -I https://anturkamchatka.ru/routes/buhta-russkaya/
HTTP/... 301
location: /morskie-progulki/buhta-russkaya/
```

До переключения хостинга нельзя отмечать задачу 301 выполненной.

## Региональные ссылки и упоминания

Приоритетные площадки для ручного партнерского обращения:

- официальный туристический портал Камчатского края: `https://visitkamchatka.ru/partners/`;
- региональные туроператоры и принимающие компании с тематическими каталогами партнеров;
- гостиницы Петропавловска-Камчатского, которым нужен проверенный морской подрядчик для гостей;
- локальные материалы о сезоне морских прогулок, безопасности и наблюдениях экипажа.

Предлагать не покупку ссылки, а полезный проверяемый материал: актуальные цены 2026, адрес пирса,
календарь морской рыбалки, погодные ограничения, свежие фото и комментарий капитана. Целевая ссылка
должна вести на наиболее подходящую посадочную страницу, а не всегда на главную.

Короткий шаблон обращения:

> Добрый день! «Антур» организует морские прогулки и морскую рыбалку из
> Петропавловска-Камчатского. Мы обновили цены, маршруты, календарь сезона 2026 и правила
> безопасности. Готовы предоставить редакции или вашим гостям фактическую справку, свежие фото с
> указанием даты и комментарий капитана. Если материал подойдет вашей аудитории, просим указать
> страницу первоисточника по соответствующему маршруту.

Фиксировать площадку, контакт, дату обращения, ответ и опубликованный URL. Упоминание считать
полученным только после проверки доступной страницы и ссылки.
