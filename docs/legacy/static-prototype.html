Вопросы

Перед выходом в море

Что будет при плохой погоде?

Маршрут и выход согласуются с учетом прогноза и безопасности. При необходимости предложим перенос.

Можно без опыта рыбалки?

Да. Формат подходит для новичков и для гостей, которые едут именно за глубоководной рыбалкой.

Можно с детьми?

Обсуждается индивидуально по маршруту, погоде и составу группы.

Киты и косатки гарантированы?

Это дикая природа, поэтому встреча не гарантируется. Маршруты проходят по акваториям, где такие встречи возможны.
